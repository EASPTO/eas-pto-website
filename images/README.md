# Photos for the EAS PTO website

Drop photo files into this folder, then tell your assistant which page each one is for.

Tips for best results:
- Landscape (wide) photos work best for banners across the top of a page.
- Portrait (tall) photos work well inside a section next to text.
- Don't worry about size or file type. Send the originals. They will be resized and optimized automatically for the web.
- iPhone photos (HEIC) are fine; they can be converted.

Once photos are added to pages, this note has no effect on the site.
